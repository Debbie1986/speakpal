# SpeakPal - 英语口语陪练应用

## 1. 产品概述

一款基于AI虚拟老师的英语口语陪练应用，通过友好的虚拟人物形象，为用户提供免费、专业的英语口语练习环境。应用参考EF英孚、TalkMe等权威英语教育机构的设计理念，让用户足不出户就能享受沉浸式英语学习体验。

### 核心价值
- **免费陪练**：无需付费，随时随地练习英语口语
- **AI虚拟老师**：友好的虚拟人物，全程陪伴学习
- **实时纠错**：即时指出发音、语法错误，帮助快速进步
- **每日建议**：根据学习情况提供个性化提升方案

### 目标用户
- 希望提升英语口语能力的普通人
- 准备雅思、托福、口语考试的学生
- 想要改善职场英语的上班族
- 对英语感兴趣但缺乏练习环境的自学者

## 2. 核心功能

### 2.1 虚拟老师形象系统

#### 老师选择
用户可以选择自己喜欢的虚拟老师形象：

| 老师名称 | 性格特点 | 擅长领域 | 适合人群 |
|----------|----------|----------|----------|
| Emma | 温柔耐心，鼓励型 | 日常口语、发音基础 | 初学者、害羞学习者 |
| James | 严谨专业，学术型 | 商务英语、正式场合 | 职场人士、考试备考 |
| Lily | 活泼开朗，轻松型 | 日常对话、流行话题 | 中级学习者、年轻群体 |
| David | 幽默风趣，激励型 | 自信表达、口音矫正 | 进阶学习者 |

#### 虚拟老师交互
- 老师有多种表情动画（微笑、思考、鼓励、惊讶等）
- 老师会根据对话内容做出相应反应
- 支持语音输出，老师可以"说话"
- 老师的语音包含自然停顿和情感变化

### 2.2 口语练习模式

#### 2.2.1 自由对话模式
- 与虚拟老师进行自由英语对话
- AI根据用户水平动态调整对话难度
- 支持多种场景：日常聊天、旅游出行、商务会议、面试准备等
- 系统实时分析用户表达，提供即时反馈

#### 2.2.2 情景模拟模式
预设的真实场景对话：

| 场景类别 | 具体场景示例 |
|----------|--------------|
| 日常生活 | 咖啡点单、餐厅订位、超市购物 |
| 旅行出行 | 机场值机、酒店入住、问路求助 |
| 职场商务 | 自我介绍、会议发言、客户沟通 |
| 社交互动 | 朋友聚会、节日祝福、观点表达 |
| 考试准备 | 雅思Part1-3、托福独立口语 |

#### 2.2.3 发音训练模式
- 跟读练习：跟读标准例句
- 单词发音：逐一练习重点单词
- 连读弱读：训练英语语流技巧
- 语调模仿：学习英语的升降调

### 2.3 错误纠正系统

#### 即时纠错
当用户表达出现错误时，系统会：

1. **温柔打断**：老师用"Actually..."或"Great try, but..."温和地指出
2. **错误高亮**：在用户输入框下方显示错误部分
3. **正确示范**：提供正确的表达方式
4. **解释说明**：简要说明错误原因
5. **再次尝试**：邀请用户重新表达

#### 纠错类型
| 错误类型 | 示例 | 纠错方式 |
|----------|------|----------|
| 发音错误 | think → sink | 标注音标，示范发音 |
| 语法错误 | I am agree → I agree | 解释主谓一致 |
| 用词错误 | I am very like → I really like | 提供更地道的表达 |
| 时态错误 | Yesterday I go → Yesterday I went | 解释时态变化规则 |

### 2.4 学习报告与建议

#### 每日学习报告
每天学习结束后，系统生成学习报告：

- **学习时长**：今日练习总时长
- **开口次数**：主动表达的句子数
- **错误统计**：各类错误的数量和比例
- **进步曲线**：与昨日相比的改善情况
- **亮点记录**：表现出色的句子

#### 个性化提升建议
基于用户当日表现，AI老师给出明日练习建议：

1. **重点练习**：根据薄弱环节推荐练习内容
2. **学习资料**：推荐相关主题的学习材料
3. **技巧提示**：针对常见问题提供技巧
4. **练习计划**：建议次日练习目标和时长

### 2.5 学习进度追踪

#### 学习数据统计
- 连续学习天数
- 累计练习时长
- 已掌握的单词和句型
- 各能力维度（流利度、准确度、词汇量）的雷达图

#### 成就系统
| 成就名称 | 解锁条件 | 奖励 |
|----------|----------|------|
| 初学者 | 完成首次对话 | 解锁表情包 |
| 连续7天 | 连续学习一周 | 解锁新老师 |
| 纠错达人 | 正确改错20次 | 获得勋章 |
| 口语达人 | 连续30天 | 解锁高级场景 |

## 3. 用户界面设计

### 3.1 设计风格
- **主题**：现代教育科技风格，友好且专业
- **主色调**：深蓝色 #2563eb（信任、专业）+ 活力橙 #f97316（活力、温暖）
- **背景色**：浅灰蓝 #f8fafc（清爽、舒适）
- **卡片风格**：圆角卡片、柔和阴影、清晰的视觉层次
- **字体**：
  - 标题：Poppins Bold
  - 正文：Noto Sans SC Regular
- **虚拟老师**：精美的2D/3D人物立绘，流畅的动画效果

### 3.2 核心页面

#### 3.2.1 首页/仪表盘
- 今日学习目标进度
- 快速开始练习按钮
- 学习数据统计卡片
- 推荐练习场景
- 每日一句励志语

#### 3.2.2 练习页面（核心场景）
| 区域 | 内容描述 |
|------|----------|
| 顶部 | 返回按钮 + 当前场景 + 设置按钮 |
| 左侧 | 虚拟老师形象（占屏幕30%） |
| 右侧 | 对话内容区域 |
| 底部 | 语音输入按钮 + 文字输入框 |
| 浮动 | 纠错提示卡片（需要时显示） |

#### 3.2.3 学习报告页面
- 日期选择器
- 学习时长图（柱状图）
- 错误分布饼图
- 能力雷达图
- AI老师建议卡片
- 历史对比

#### 3.2.4 个人中心
- 用户头像和等级
- 学习数据总览
- 成就展示
- 老师选择/解锁
- 设置（语音、通知等）

### 3.3 交互设计

#### 语音输入流程
1. 用户点击麦克风按钮
2. 显示"正在聆听..."动画
3. 用户说话，实时显示语音波形
4. 识别完成，文字出现在输入框
5. 用户确认或编辑后发送

#### 错误纠正动画
1. 老师头像旁显示问号气泡
2. 错误文字以红色高亮闪烁
3. 正确表达以绿色文字出现
4. 解释说明以淡入方式展示
5. "再试一次"按钮弹出

  id: string;
  role: 'user' | 'ai';

## 5. 技术实现要点

### 5.1 前端技术栈
- React 18 + TypeScript
- Tailwind CSS
- Vite 构建工具
- React Router
- Framer Motion（动画效果）
- Web Speech API / 第三方语音SDK

### 5.2 语音识别方案
- 优先使用浏览器原生 Web Speech API
- 支持语音转文字（SpeechRecognition）
- 语音合成（SpeechSynthesis）用于AI回复

### 5.3 AI对话处理
- 使用本地模拟对话系统
- 预设丰富的对话模板
- 关键字匹配实现基础纠错
- 模拟AI老师的智能回复

### 5.4 PWA支持
- Service Worker 实现离线缓存
- Web App Manifest 支持添加到桌面
- 后台推送通知（可选）

## 6. 场景对话示例

### 6.1 咖啡点单场景
```
AI老师: Hi! Welcome to Coffee Corner. What can I get for you today?
用户: I want a coffee please.
AI老师: Great! Would you like a hot or iced coffee?
用户: Hot coffee.
AI老师: Perfect! And what size would you like? Small, medium, or large?
用户: A large please.
AI老师: Excellent choice! We also have some delicious pastries. Would you like one?
用户: Yes, I want a cake.
AI老师: Actually, we don't have cake today, but we have brownies and croissants. Would you like one of those? "I want" is a bit direct. In customer service situations, you could say "Could I have..." or "I'll have..." to sound more polite. Try again? 
用户: Could I have a brownie?
AI老师: Perfect! That's much more natural. "Could I have..." is a great polite expression. A brownie and a large hot coffee. Anything else?
用户: No, that's all.
AI老师: Great! Your total is $6.50. Please wait at the pickup counter.
用户: Thank you!
AI老师: Wonderful conversation! Your English sounds very natural. Here's my feedback: [显示纠错详情和学习建议]
```

### 6.2 每日建议生成
```
根据今日学习情况，Emma给出以下建议：

📚 明日重点练习：
• 今天你在"过去时"的使用上有3次错误，建议复习规则动词和不规则动词的过去式变化
• 你的词汇量在日常场景表现不错，但在表达观点时有些词穷，建议积累一些观点表达句型

💡 技巧提示：
• 尝试使用 "I believe that..." "In my opinion..." 等句式来表达观点，会显得更专业

⏰ 练习建议：
• 建议明天练习15-20分钟的"观点表达"场景
• 可以尝试用英语描述今天发生的事，练习过去时的使用
```
